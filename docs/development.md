# Development

The README, user guide, architecture notes, and validation record define the
current supported contract. Older changelog claims of universal pixel identity
or standards compliance are historical, not guarantees.

Keep changes scoped to course constructs. Add behavioral regressions for semantic
fixes, not only tag counts. Compile into adjacent out folders and run the shared
tests/run_tests.py runner. Compiler success alone is not an accessibility result.

Complex merged tables, MathML navigation, additional overlay commands, note
reference navigation, second-screen notes, other engines, and independent PDF/UA
certification require separate work beyond the current supported contract.
